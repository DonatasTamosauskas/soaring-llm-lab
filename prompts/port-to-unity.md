# Port the Godot game to Unity

- Used by: Sol 6.1 · Unity port of Opus 5.5
- Source: the run's first message (Codex log).

---

Your task is to take the VR godot game that has been built in this directory, and to build a version of it in Unity 6.6. The reason for this is to take advantage of the more mature ecosystem of unity VR to improve the visuals and performance of the game on the Meta Quest Pro headset.

Please make all of your work in a separate sub-directory. Work until you have completely recreated the game using Unity's best practices. Environment facts (macOS dev, Quest Pro target):
- Use Unity CLI for your work. Locally Unity 6.6 is installed.
- Use MetaXRSimulator to simulate a VR device (Meta Quest Pro).
- Review the following repository for an example and learnings how to set up a Meta Quest project in Unity via CLI: /Users/don/Projects/Soaring/vr-unity-example
