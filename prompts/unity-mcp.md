# Prompt history
Your task is to build a VR game inspired by the likes of Gorilla Tag and Agar.io, with the core mechanic being bird-like flight. Instead of gorilla-like movement, movement is performed by flapping the wings (controllers), by tilting the wings to achieve different lift characteristics for faster, slower flight and turns all inspired by real bird-like movements. The game world should have vast open spaces and many areas for intricate flight dynamics - such as tree branches, windows, electric poles, etc. - all the things that birds cling to and make acrobatic flight around. The game loop - catch birds that are smaller than yourself while avoiding being caught by birds larger than you. You grow as you catch more birds. Build the game in Unity, use all the tools at our disposal, especially Unity MCP and make sure you only finish work once the core mechanic of flight is perfected. For interaction with the XR environment use the Meta XR Simulator.
